A solar-powered Meshtastic node mounted on my roof, joining the local LoRa mesh. It's long-range, low-power radio that works with no internet and no cell service. I configured remote administration over the mesh itself, so
I can manage it without going up there, and added a fixed gateway feeding mesh status into Home Assistant.
