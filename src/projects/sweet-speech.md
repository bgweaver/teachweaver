A site for a private speech therapy practice. Warm and professional was the brief, so it ended up with a
watercolor palette and a layout built around what parents actually need to find first. Netlify Forms for
contact, no backend to maintain. I also learned to take image optimization seriously on this one, since some
of the source photos were several megabytes each.
