Originally a hand-written Bootstrap site where every page carried its own copy of the header, nav, and footer,
and every new post meant editing a JSON file by hand. Rebuilt on Eleventy so a post is now just a markdown
file. Migrating it turned up a dozen small inconsistencies the old process had quietly introduced, a good argument for letting the build do the repetitive parts.
